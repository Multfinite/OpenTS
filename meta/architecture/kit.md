# Архитектура домена `kit`

## Устройство каркаса

| Слой | Что | Кто меняет |
| --- | --- | --- |
| `HYAI/core/kernel/` | Инварианты, форматы, процессы | только владелец |
| `HYAI/core/domains/` | Домены и профили | домены; другие домены — через `kit` |
| `HYAI/tools/` | Движки без доменных знаний | владелец домена `kit` |
| `HYAI/meta/` | Рамки проекта и доменов | домены в своей части |

## Инварианты

| ID | Инвариант | Чем проверяется |
| --- | --- | --- |
| `KIT-INV-01` | Движки не содержат доменных имён (`KIT-POL-07`) | `check_domains.py` (скан литералов) |
| `KIT-INV-02` | Заблокированные зоны покрыты `require_approval_for` | `check_manifest.py` |
| `KIT-INV-03` | Новый домен проходит проверки без правок ядра | тест «домен из `_template`» |

## Анти-паттерны

| Не делаем | Почему | Что вместо |
| --- | --- | --- |
| Домен ради каталога (`KIT-POL-05`) | Нормативная база пуста, проверки формальны | Профиль существующего домена |
| Правка скрипта под домен (`KIT-POL-07`) | Доменное знание протекает в движок | Данные в `domains/*/` |
| Профиль с правами (`KIT-POL-09`) | Права размножаются по профилям | Зона + `cross_scope` |
| `kit`, меняющий сам себя (`KIT-POL-01`) | Правила проверки перестают быть проверяемыми | Решение владельца |
