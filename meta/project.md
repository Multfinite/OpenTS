# Паспорт проекта

Этот файл читает каждый агент в любой задаче. Здесь зафиксированы идентичность `OpenTS`, активные домены, иерархия источников истины и границы экспорта.

## Идентичность

| Поле | Значение |
| --- | --- |
| Название | OpenTS `[И] README.md` |
| Что делает | Открытая реконструкция и платформа для моддинга движка *Command & Conquer: Tiberian Sun* (2.03 Firestorm) в виде самостоятельного исполняемого приложения `[И] README.md` |
| Для кого | Игроки, моддеры и разработчики движка на Windows 10 1903+ (`Win32` и `x64`) `[И] docs/BUILDING.md` |
| Владелец | `Multfinite` `[А]` |
| Статус | `0.1.0` (`GPL-3.0-or-later`) `[И] CMakeLists.txt`, `[И] LICENSE.md` |

## Активные домены

| Домен | Каталоги продукта | Зачем подключён |
| --- | --- | --- |
| `software` | `code/`, `cmake/`, `tests/`, `ui/` | C++/CMake-движок, модульные тесты и документы интерфейса |
| `docs` | `docs/` | Техническая документация по сборке, направлению архитектуры и форматам |

Домен, которого нет в этой таблице, не должен встречаться в отчётах: `check_report.py` сверяет состав с `active` в `meta/manifest.yaml`.

## Иерархия источников истины

1. Решение владельца (`meta/decisions/project/`, `P-*`) и проектные политики (`meta/policies/`, `PRJ-POL-*`) `[А]`.
2. Политики ядра и активных доменов `HYAI` (`HYAI/HYAI/core/`) `[А]`.
3. Решение домена (`meta/decisions/<domain>/`).
4. Контракт: формат сейвов и сетевых пакетов, INI/скриптовые схемы, публичные заголовки модулей, тесты `tests/`.
5. Реализация: `code/`, `cmake/`, `ui/`.
6. Документация (`docs/`, `manual/`).

Нижний уровень не отменяет верхний; унаследованные агентские рекомендации апстрима не имеют силы над контрактами `HYAI` (`P-0001`) `[А]`.

## Карта репозитория

| Путь | Что |
| --- | --- |
| `code/` | Исходный код движка C++ (`software`) `[И] CMakeLists.txt` |
| `cmake/`, `CMakeLists.txt` | Сценарии сборки CMake и тулчейны (`software`) `[И] docs/BUILDING.md` |
| `tests/` | Автономные тесты CTest без проприетарных ассетов (`software`) `[И] docs/BUILDING.md` |
| `ui/` | Документы, стили и шрифты интерфейса RmlUi (`software`) `[И] docs/BUILDING.md` |
| `thirdparty/` | Вендоризованные зависимости и сабмодули движка (`bgfx`, `SDL`, `RmlUi`, `freetype`, `imgui`, `miniaudio`, `lzo`) `[И] .gitmodules` |
| `docs/` | Документация по сборке, архитектуре и истории реконструкции (`docs`) `[И] docs/BUILDING.md` |
| `manual/` | Справочник INI/скриптов с собственным генератором `manual/tools/manage.py` `[И] manual/README.md` |
| `HYAI/` | Внешний подмодуль каркаса `HYAI` (ядро, шаблоны, встроенные проверки) `[А]` |
| `meta/` | Проектные данные `HYAI`: манифест, политики, архитектура, словари, решения, отчёты `[А]` |
| `tools/` | Проектные движки `HYAI`, включая `tools/export_branch.py` для чистого экспорта `[А]` |

## Чего в проекте нет

- Оригинальных игровых ассетов, карт, аудио и бинарников *Tiberian Sun* в Git (`[И] docs/BUILDING.md`).
- Следов и артефактов `HYAI` в экспортных ветках для главного репозитория: при экспорте результата задачи действует [`meta/policies/export.md`](policies/export.md) (`PRJ-POL-01..06`, `P-0001`) `[А]`.
