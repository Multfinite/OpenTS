# Термины домена `kit`

| Термин | Значение |
| --- | --- |
| `ядро` | `HYAI/core/kernel/` — правила, действующие во всех доменах, и движки проверок |
| `домен` | Предметная область со своей нормативностью и своим доступом |
| `профиль` | Тема, задача и мыслительный процесс внутри домена |
| `активная конфигурация` | Список пар «домен + профиль» в `active` манифеста |
| `движок` | Скрипт в `HYAI/tools/`, не знающий имён доменов |
| `оверлей` | Доменная часть схемы frontmatter в `HYAI/meta/schema/domains/` |
| `зона одобрения` | Путь из `permissions.write.require_approval_for`: меняется только владельцем |
| `дрейф сборки` | Расхождение `AGENTS.md` с результатом `assemble_agents.py` |
