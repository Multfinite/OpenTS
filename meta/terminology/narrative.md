# Термины домена `narrative`

| Термин | Значение |
| --- | --- |
| `канон` | Совокупность утверждённых фактов; то, что нельзя отменить молча |
| `core` | Жёсткий инвариант мира: физика, магия, правила существования |
| `setting` | Устройство мира: страны, институты, экономика |
| `деталь` (`detail`) | Уточнение: имя, дата, второстепенный факт |
| `подача` (`presentation`) | Стиль и композиция; фактов не меняет |
| `призма` | Точка зрения, через которую строится проекция: `omniscient`, `scenario`, `characters`, `audience` |
| `компетенция` | Способность субъекта **понять** сведения, шкала `У0…У14`, `УН` — не знает |
| `карта понимания` | Блок отчёта: кто из субъектов что понял и почему |
| `спойлер` | Сведение, известное автору, но не читателю |
| `проекция` | Версия корпуса для конкретной пары «роль × призма» |

Различие «знает» и «понимает» — центральное для домена: персонаж может быть носителем сведения и не быть способен его осмыслить (`access.md`, шкала компетенций).
