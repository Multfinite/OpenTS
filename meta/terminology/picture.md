# Термины домена `picture`

| Термин | Значение в домене `picture` |
| --- | --- |
| `<picture_root>` | Действующий корень данных из `root_paths` манифеста активного домена `picture`: `HYAI/core/domains/picture/pictures` в самом HYAI и собственный каталог проекта вне подмодуля во внешних проектах (`PIC-POL-06`) |
| `Ворота G0-SAF` | Блокирующая стартовая проверка явного задания пользователем всех четырёх правил безопасности (`NSFW`, `Copyright`, `Person`, `Violence`, `PIC-SAF-01`) |
| `Каркас 5+3` | Каноническая структура промпта: 5 содержательных секций (`subject`, `environment`, `lighting`, `camera`, `style`) + 3 управляющих блока (`negative`, `weights`, `render_params`, `PIC-PRM-01`) |
| `MinDetail` | Порог минимальной детализации позитивных секций промпта в значимых токенах (`>= N`) для сложных сцен без пустых усилителей качества (`PIC-PRM-02`) |
| `Динамический negative` | Негативная секция промпта, автоматически конструируемая и пополняемая под сюжет, ракурс, ограничения безопасности и дефекты прошлых попыток (`PIC-POL-02`, `PIC-PRM-03`) |
| `Instant` (`picture/instant`) | Однопроходный рабочий процесс, где каждая попытка создаёт одно целое базовое изображение сцены через промпт (`PIC-WF-01`) |
| `Pipeline` (`picture/pipeline`) | Многозвенный конвейер, создающий через отдельные промпты промежуточные звенья (`layout`, `scene-block`, `background`, `subjects`, `lighting`, `masks-guides`) с поштучной VLM-приёмкой до сборки `base-final` (`PIC-WF-01..02`) |
| `Промежуточное звено` (`stage`) | Принятый VLM этап генерации или конечный базовый кадр до стилизации; обязательно сохраняется в `<picture_root>/stages/` в отличие от удаляемых неудачных попыток (`PIC-POL-04`) |
| `base-neutral` | Режим секции `style` на этапах построения сцены и звеньев: честная передача формы, объёма и материалов без финального стилевого фильтра (`PIC-POL-05`) |
| `base-final` | Полностью готовое и прошедшее содержательную/анатомическую VLM-приёмку конечное базовое изображение перед наложением фильтра стиля (`PIC-POL-05`) |
| `style-filter` (`target-style`) | Заключительный промпт-проход наложения целевого стиля с замком содержания (`content-lock`), выполняемый строго после готовности `base-final` (`PIC-POL-05`) |
| `series-anchor` | Эталон консистентности серии (`visual-canon`), закрепляющий инварианты внешности персонажа, ключевых предметов, палитры и единого финального стиля (`PIC-QA-04`) |
| `Iteration Limit` | Жёсткий верхний предел числа попыток генерации звена или кадра, защищающий от бесконечного цикла (`PIC-QA-05`) |
