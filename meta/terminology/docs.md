# Термины домена `docs`

| Термин | Значение |
| --- | --- |
| `ТЗ` (`requirements`) | Техническое задание: что должно стать возможным и как это примут |
| `спецификация` (`spec`) | Как устроено и почему так: компоненты, потоки, отказы |
| `требование` | Проверяемое утверждение о должном, с `REQ-ID` и критерием приёмки |
| `руководство` (`guide`) | Документ для читателя: как сделать X |
| `диаграмма` (`diagram`) | Текстовая схема, отвечающая на один вопрос |
| `normative` | Должное: обязательно к исполнению |
| `descriptive` | Сущее: описывает систему как она есть |
| `критерий приёмки` | Условие, по которому видно, что требование выполнено |
