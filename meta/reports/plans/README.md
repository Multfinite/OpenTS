# Планы

Здесь лежат артефакты, которые **не являются отчётами о выполненной работе**: планы миграций, матрицы решений, черновые схемы.

Почему отдельно: в исходной системе такие файлы лежали в корне отчётов и валились проверкой `check_report.py`, потому что у них нет разделов «Задача / Что сделано / Проверка». Ошибка была не в файлах, а в отсутствии места.

Правила:
1. Файл плана не проходит `check_report.py` и не обязан: это не отчёт.
2. План, ставший работой, порождает отчёт в `reports/<domain>/`.
3. Устаревший план удаляется, а не архивируется: архив планов — это способ ничего не решать.
