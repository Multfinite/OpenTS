# Архив

Отчёты старше года или относящиеся к завершённым проектам. Переносятся сюда с сохранением имени файла и пути `reports/<domain>/YYYY/`.

Правила:
1. Архив не проверяется `check_report.py`.
2. Перенос в архив не меняет содержание отчёта: правки задним числом запрещены (`HYAI-PROV-08`).
3. Отчёт, на который ссылается действующее решение, не архивируется: сначала решается судьба ссылки.
