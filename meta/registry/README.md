# Реестры документов

Здесь лежит [`documents.yaml`](documents.yaml) — репозиторный список «прочитай это до работы». Доменные списки живут рядом с доменами: `HYAI/core/domains/<domain>/registry/documents.yaml`.

Правило: `id` уникален **глобально** между всеми реестрами (`HYAI-ART-12`), иначе ссылка «см. `sw.policy`» станет неоднозначной.
